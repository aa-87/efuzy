# EFUZY Buyer Handoff Checklist

Use this checklist before sending a customer-ready package.

## Package readiness

- Release version is correct.
- Edition is correct.
- Release archive exists.
- Release checksums exist.
- Release notes exist.
- Delivery bundle was rebuilt for this customer.
- Delivery bundle verification passed.

## Customer metadata

- Customer name is correct.
- Quote or order reference is correct.
- Delivery archive name is correct.
- Edition naming matches the commercial offer.

## Documentation

- Install guide included.
- Admin guide included.
- Licensing guide included.
- Delivery guide included.
- Changelog included.

## Installer contents

- `install_efuzy.sh` included.
- `compile_efuzy.sh` included.
- `check_efuzy.sh` included.
- `start_efuzy.sh` included.
- `mws.conf.json` included.

## Commercial clarity

- Buyer knows whether this is Standard, Professional, or Enterprise.
- Buyer knows whether source is included.
- Buyer knows whether onboarding is included.
- Buyer knows support boundaries.
- Buyer knows how upgrades will be delivered.

## Final send

- Delivery archive attached or made available.
- Checksums shared.
- First-step message prepared.
- Install/licensing contact path included.
